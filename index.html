Compose Anywhere

A proof of concept for visual component placement on any website

What is this?

A simple tool that lets you visually place components (forms, widgets, etc.) on any website and generate the embed code. It's currently just a POC exploring the idea.

How it works

  1. Configure your component using our basic installer
  2. Generate a bookmarklet with your settings
  3. Use the bookmarklet on any website to place your component
  4. Get the embed code to make it permanent
