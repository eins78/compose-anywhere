# Compose Anywhere - Project Guidelines

## Product Name
- **Full Name**: Compose Anywhere
- **Short Name**: compose-anywhere
- **Repository**: `compose-anywhere`
- **npm package**: `compose-anywhere` (when published)

## Terminology

### Always Use:
- **Component** - The embeddable element (not "widget")
- **Placement** - The act of positioning
- **Embed Code** - The generated code snippet
- **Container** - Target elements on the page
- **Visual placement** - The interactive preview

### Project Description

**Short**: "Visual component placement tool"

**Long**: "Compose Anywhere is a visual placement tool that enables seamless component integration on any website through intelligent container detection, visual preview, and instant embed code generation."

## Key Messages

### Tagline
> "Drop any component on any website"

### Value Proposition
> "Compose Anywhere enables visual component placement with smart detection and instant embed code generation - no dependencies, works everywhere."

### Key Benefits
1. **See Before You Embed** - Visual preview
2. **Smart Detection** - Intelligent container recognition
3. **Zero Conflicts** - Isolated with Shadow DOM
4. **Instant Code** - One-click generation
