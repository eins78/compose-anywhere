# /review - Manual Review Command

Prepares the project for manual review and opens relevant test URLs.

## What it does:
1. Ensures the local server is running
2. Opens the main project pages in browser
3. Provides testing instructions

## Usage:
```
/review
```

## Testing checklist:
- Homepage loads correctly
- Installer page shows live preview
- Color changes update preview in real-time
- Generated bookmarklet can be dragged to bookmarks
- Test pages work with the bookmarklet
- Container detection highlights valid areas
- Component placement works on click
