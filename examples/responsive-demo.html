Width Breakpoint Testing

Components adapt to these different container widths using container queries

Mobile (Narrow) 280px

At this width, components show a minimal layout:

  • Stacked elements
  • No illustration
  • Compact form
  • Vertical button layout
Tablet (Medium) 400px

At 400px+ width, components show enhanced layout:

  • Side-by-side elements
  • Small illustration appears
  • Horizontal form layout
  • Better typography
Desktop (Large) 600px

At 600px+ width, components show full layout:

  • Optimized spacing
  • Large illustration
  • Enhanced typography
  • Better visual hierarchy
Wide (Maximum) 800px

At maximum width, components are centered and optimized:

  • Centered layout
  • Maximum readability
  • Optimal component size
  • Professional appearance
